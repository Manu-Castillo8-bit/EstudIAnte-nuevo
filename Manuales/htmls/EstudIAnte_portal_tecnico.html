01 / Visión general

Una plataforma para apoyar el aprendizaje con tecnología.

EstudIAnte es una plataforma multiplataforma orientada a apoyar el aprendizaje mediante Inteligencia Artificial. Según el manual, permite gestionar tutorías personalizadas, resolver autoevaluaciones, generar esquemas visuales en Mermaid, analizar documentos multiformato y supervisar la actividad global mediante un panel administrativo unificado.

Tutorías personalizadasAutoevaluacionesDiagramas visualesAnálisis documentalPanel administrativo

02 / Componentes y servicios

Las piezas identificadas en la documentación.

📱Aplicación cliente

Interfaz indicada para Android y equipos de escritorio Windows.

☁️Supabase

Backend mencionado para autenticación, almacenamiento y sincronización en tiempo real.

✦Funciones de IA

Generan contenido para cuestionarios, diagramas y análisis o resúmenes documentales.

⌘Mermaid

Permite representar información en diagramas a partir de una estructura de código.

▤Módulo documental

Acepta archivos PDF, DOCX y TXT, con un límite declarado de 20 MB por archivo.

▦Panel administrativo

El documento menciona un panel unificado para supervisión global.

ⓘ
Nota de alcance
El manual no especifica el proveedor ni la configuración concreta de IA. Tampoco documenta los detalles internos del panel administrativo.
⌘

03 / Requisitos del sistema

Comprueba estas condiciones antes de utilizar la plataforma.

🤖

Android

  • Android 8.0 (Oreo) o superior.
  • Entre 50 y 100 MB libres declarados para instalación y caché.
  • Internet y permisos para seleccionar archivos locales.
🖥️

Escritorio

  • Windows 10 u 11.
  • Compatibilidad indicada con .NET MAUI.
🌐

Conectividad

  • Conexión activa a Internet.
  • Autenticación, almacenamiento y sincronización dependen del backend Supabase.

05 / Diagnóstico de fallos

Primeras verificaciones antes de escalar una incidencia.

ProblemaPosible causaAcción inicial
“Comprobando conexión con Supabase”Sin Internet o comunicación con el backend bloqueada.Comprobar Internet y si la red bloquea el servicio en la nube.
“Generar con IA” no respondeFuente no válida o vacía; chat sin mensajes o documento que no está “Listo”.Seleccionar una fuente válida y activa y volver a intentar.
Archivo no carga o formato erróneoFormato distinto de PDF/DOCX/TXT o archivo mayor de 20 MB.Verificar el formato y tamaño antes de subirlo otra vez.
La sesión no iniciaCredenciales incorrectas o problema de conexión con autenticación.Revisar usuario/correo, contraseña y conexión; escalar si continúa.

Protocolo de escalamiento

Registrar entorno

Sistema operativo y dispositivo.

Documentar el fallo

Módulo, acción exacta y mensaje literal.

Reportar

Indicar si se repite y qué comprobaciones se hicieron; enviar al equipo por canales internos.

06 / Seguridad y operación responsable

Buenas prácticas recomendadas por el manual.

✓

Protege tus credencialesMantén privadas tus contraseñas y datos de acceso.

✓

Recuerda tu sesión con cuidadoUsa “Recordar sesión” solo en dispositivos personales o de confianza.

✓

Cuida los documentosNo cargues archivos sensibles sin autorización para procesarlos mediante los servicios configurados.

✓

Evita exponer secretosNo incluyas claves privadas, tokens ni secretos de configuración en capturas o reportes.

🛡
Al reportar una incidencia
Incluye el módulo afectado, los pasos realizados y el texto exacto del error. Omite siempre datos confidenciales.
